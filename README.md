# Data Warehouse Project

- Step by Step Instructions

1. First go to the Mesh-Join folder and run the "initial_setup.sql" file.
2. Secondly, in the Mesh-Join folder open the command prompt and run "py terminal.py"
3. Enter the requested credentials. Enter 0 to begin the process from scratch.
4. Once that is done the project begins to run, you can enter the commands: help, quit, clear, peak, non-peak, periodic, both, online, status. 
5. I added a new command "change" that allows you to change the value of peak and non-peak.
